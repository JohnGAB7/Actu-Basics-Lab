Tool 01 · Spreadsheet

Excel — analyse and validate

Goal: build an auditable table without programming.

Guided exercise

  1. Open the CSV in Excel and convert the range into a table named DataTable.
  2. Add three columns: frequency per 100 exposures, incurred per exposure and claims-to-premium ratio.
  3. If the columns remain A:E, use the formulas below in the first data row and fill down.
  4. Add a total row and calculate ratios from totals, never from a simple average of percentages.
  5. Create a chart comparing incurred per exposure across segments and explain what it cannot establish.
F2 = C2/B2*100 · G2 = E2/B2 · H2 = E2/D2

In an Excel table, prefer structured references such as =[@Claims]/[@Exposure]. Function names and separators may vary with Excel language and settings.

Tool 02 · Automation

Excel VBA — repeat without errors

Goal: generate an aggregate summary in one click, without automating a process before understanding it.

Before running the macro

  1. In Excel, name the data worksheet Data.
  2. Check columns A:E follow the CSV order and headers are in row 1.
  3. Open the VBA editor, insert a standard module and paste the code.
  4. Run BuildPortfolioSummary. The macro creates or clears the Summary worksheet.
Option Explicit

Sub BuildPortfolioSummary()
    Dim ws As Worksheet, out As Worksheet
    Dim lastRow As Long, r As Long
    Dim exposure As Double, claims As Double
    Dim premium As Double, incurred As Double

    Set ws = ThisWorkbook.Worksheets("Data")
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row

    On Error Resume Next
    Set out = ThisWorkbook.Worksheets("Summary")
    On Error GoTo 0

    If out Is Nothing Then
        Set out = ThisWorkbook.Worksheets.Add(After:=ws)
        out.Name = "Summary"
    Else
        out.Cells.Clear
    End If

    For r = 2 To lastRow
        exposure = exposure + CDbl(ws.Cells(r, 2).Value)
        claims = claims + CDbl(ws.Cells(r, 3).Value)
        premium = premium + CDbl(ws.Cells(r, 4).Value)
        incurred = incurred + CDbl(ws.Cells(r, 5).Value)
    Next r

    out.Range("A1").Value = "Portfolio indicator"
    out.Range("B1").Value = "Value"
    out.Range("A2").Value = "Exposure"
    out.Range("B2").Value = exposure
    out.Range("A3").Value = "Claims"
    out.Range("B3").Value = claims
    out.Range("A4").Value = "Frequency per 100 exposures"
    out.Range("B4").Value = claims / exposure * 100
    out.Range("A5").Value = "Premium (EUR)"
    out.Range("B5").Value = premium
    out.Range("A6").Value = "Incurred claims (EUR)"
    out.Range("B6").Value = incurred
    out.Range("A7").Value = "Incurred per exposure (EUR)"
    out.Range("B7").Value = incurred / exposure
    out.Range("A8").Value = "Loss ratio"
    out.Range("B8").Value = incurred / premium
    out.Range("B4").NumberFormat = "0.00"
    out.Range("B5:B7").NumberFormat = "#,##0.00"
    out.Range("B8").NumberFormat = "0.00%"
    out.Columns("A:B").AutoFit
End Sub

Prerequisite: desktop Excel with macros enabled. Only enable macros from code whose provenance you trust. This code assumes valid numeric values and a non-empty portfolio; production code should handle these errors explicitly.

Tool 03 · Programming

Python — reproduce the analysis

Goal: import data, calculate indicators and produce reproducible output with the standard library.

Guided exercise

  1. Install Python 3 if needed.
  2. Place the script at the repository root, where the data folder is accessible.
  3. Run python workshop.py.
  4. Then add a zero-division guard and checks for missing values.
import csv
from pathlib import Path

file_path = Path("data/atelier-sinistres-synthetiques.csv")

with file_path.open(newline="", encoding="utf-8") as file:
    rows = list(csv.DictReader(file))

exposure = sum(int(row["exposure"]) for row in rows)
claims = sum(int(row["claims"]) for row in rows)
premium = sum(float(row["premium_eur"]) for row in rows)
incurred = sum(float(row["incurred_eur"]) for row in rows)

print(f"Exposure: {exposure:,}")
print(f"Claims: {claims:,}")
print(f"Frequency per 100 exposures: {claims / exposure * 100:.2f}")
print(f"Incurred per exposure: {incurred / exposure:.2f} EUR")
print(f"Aggregate loss ratio: {incurred / premium:.2%}")

for row in rows:
    freq = int(row["claims"]) / int(row["exposure"]) * 100
    print(row["segment"], f"{freq:.2f} claims per 100 exposures")

Extension: reproduce the results with pandas, then add automated tests and a chart. The statistical calculation should remain understandable independently of the library.

Tool 04 · Statistics

R — explore and interpret

Goal: perform the same calculations and extend the analysis to visualisation and diagnostics.

Guided exercise

  1. Open RStudio at the project root or adjust the file path.
  2. Import the CSV with read.csv.
  3. Calculate aggregates and indicators by segment.
  4. Compare results with Excel, VBA and Python.
  5. Plot incurred per exposure and write a cautious interpretation.
data <- read.csv(
  "data/atelier-sinistres-synthetiques.csv",
  stringsAsFactors = FALSE
)

total_exposure <- sum(data$exposure)
total_claims <- sum(data$claims)
total_premium <- sum(data$premium_eur)
total_incurred <- sum(data$incurred_eur)

cat("Exposure:", total_exposure, "\n")
cat("Claims:", total_claims, "\n")
cat("Frequency per 100 exposures:",
    100 * total_claims / total_exposure, "\n")
cat("Incurred per exposure:",
    total_incurred / total_exposure, "EUR\n")
cat("Aggregate loss ratio:",
    total_incurred / total_premium, "\n")

data$frequency_per_100 <- 100 * data$claims / data$exposure
data$incurred_per_exposure <- data$incurred_eur / data$exposure
data$loss_ratio <- data$incurred_eur / data$premium_eur

print(data[, c("segment", "frequency_per_100",
               "incurred_per_exposure", "loss_ratio")])

barplot(data$incurred_per_exposure,
        names.arg = data$segment,
        xlab = "Segment",
        ylab = "Incurred EUR per exposure",
        main = "Synthetic portfolio comparison")

Extension: compare mean and median, study dispersion, document assumptions and produce a reproducible report with Quarto.

Check your understanding

What you should be able to explain

The skill is not just obtaining the same numbers: it is knowing what they measure.

  1. Why is the aggregate ratio not the simple average of segment ratios?
  2. Why is claim frequency per exposure not necessarily an individual probability?
  3. How would a mismeasured exposure affect segment comparisons?
  4. Why is incurred per exposure not, by itself, a sufficient tariff pure premium?
  5. What additional information would be needed before proposing a pricing change?

Success criterion: you can calculate, validate, interpret and state at least two limitations of the analysis.
