# Ateliers logiciels — Bloc 2

Les ateliers sont des compléments aux cours. Ils vérifient les calculs et permettent d'explorer les dimensions, les algorithmes et les limites numériques ; ils ne remplacent pas les preuves.

## AL01 — Vecteurs
- [Python — vecteurs et géométrie](python/al01_vecteurs.py) : opérations, produit scalaire, norme, distance et angle, avec contrôles de dimensions.
- [R — vecteurs et géométrie](r/al01_vecteurs.R) : implémentation en R de base, sans dépendance externe.

Les ateliers Python et R sont des scripts pédagogiques autonomes. Ils doivent être exécutés et testés dans un environnement approprié avant d'être présentés comme validés sur une plateforme.
