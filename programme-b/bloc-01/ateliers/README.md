# Ateliers pratiques — Bloc 1

Ces ateliers ne remplacent pas le raisonnement mathématique : le code sert à vérifier, explorer et automatiser des calculs dont les hypothèses doivent être comprises.

## Environnements
- Python 3.10+ ; le script principal utilise uniquement la bibliothèque standard.
- R 4.0+ ; le script principal utilise uniquement les fonctions de base.
- Excel : formules documentées dans `excel/FORMULES.md`.
- VBA : module importable dans l'éditeur Visual Basic.

## Exécution
Depuis la racine du dépôt :
```bash
python programme-b/bloc-01/ateliers/python/fondations.py
Rscript programme-b/bloc-01/ateliers/r/fondations.R
```

Les scripts comportent des assertions de contrôle. Un résultat informatique cohérent ne garantit pas que le modèle posé soit pertinent : contrôler les unités, le domaine et le sens métier.
