Outil 01 · Tableur

Excel — analyser et contrôler

Objectif : construire un tableau vérifiable sans programmation.

Exercice guidé

  1. Ouvre le CSV dans Excel et transforme la plage en tableau nommé Donnees.
  2. Ajoute trois colonnes : fréquence pour 100 expositions, coût par exposition et ratio sinistres/primes.
  3. Sur la première ligne de données, si les colonnes restent A:E, utilise les formules ci-dessous, puis recopie-les.
  4. Ajoute une ligne de total et calcule les ratios à partir des totaux, jamais par moyenne simple des pourcentages.
  5. Crée un graphique comparant le coût par exposition entre segments et explique ce qu'il ne permet pas de conclure.
F2 = C2/B2*100 · G2 = E2/B2 · H2 = E2/D2

Dans un tableau Excel structuré, préfère les références structurées, par exemple =[@Sinistres]/[@Exposition]. Les noms de fonctions et séparateurs peuvent varier selon la langue et la configuration d'Excel.

Outil 02 · Automatisation

Excel VBA — répéter sans erreur

Objectif : générer une synthèse agrégée en un clic, sans automatiser prématurément un processus mal compris.

Avant de lancer la macro

  1. Dans Excel, nomme la feuille contenant les données Data.
  2. Vérifie que les colonnes A:E suivent l'ordre du CSV et que les en-têtes sont sur la ligne 1.
  3. Ouvre l'éditeur VBA, insère un module standard et colle le code.
  4. Lance BuildPortfolioSummary. La macro crée ou remplace le contenu de la feuille Summary.
Option Explicit

Sub BuildPortfolioSummary()
    Dim ws As Worksheet, out As Worksheet
    Dim lastRow As Long, r As Long
    Dim exposure As Double, claims As Double
    Dim premium As Double, incurred As Double

    Set ws = ThisWorkbook.Worksheets("Data")
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row

    On Error Resume Next
    Set out = ThisWorkbook.Worksheets("Summary")
    On Error GoTo 0

    If out Is Nothing Then
        Set out = ThisWorkbook.Worksheets.Add(After:=ws)
        out.Name = "Summary"
    Else
        out.Cells.Clear
    End If

    For r = 2 To lastRow
        exposure = exposure + CDbl(ws.Cells(r, 2).Value)
        claims = claims + CDbl(ws.Cells(r, 3).Value)
        premium = premium + CDbl(ws.Cells(r, 4).Value)
        incurred = incurred + CDbl(ws.Cells(r, 5).Value)
    Next r

    out.Range("A1").Value = "Portfolio indicator"
    out.Range("B1").Value = "Value"
    out.Range("A2").Value = "Exposure"
    out.Range("B2").Value = exposure
    out.Range("A3").Value = "Claims"
    out.Range("B3").Value = claims
    out.Range("A4").Value = "Frequency per 100 exposures"
    out.Range("B4").Value = claims / exposure * 100
    out.Range("A5").Value = "Premium (EUR)"
    out.Range("B5").Value = premium
    out.Range("A6").Value = "Incurred claims (EUR)"
    out.Range("B6").Value = incurred
    out.Range("A7").Value = "Incurred per exposure (EUR)"
    out.Range("B7").Value = incurred / exposure
    out.Range("A8").Value = "Loss ratio"
    out.Range("B8").Value = incurred / premium
    out.Range("B4").NumberFormat = "0.00"
    out.Range("B5:B7").NumberFormat = "#,##0.00"
    out.Range("B8").NumberFormat = "0.00%"
    out.Columns("A:B").AutoFit
End Sub

Prérequis : Excel de bureau avec macros activées. N'active les macros que pour du code dont tu connais la provenance. Le code suppose des valeurs numériques valides et un portefeuille non vide ; une version de production devrait gérer explicitement ces erreurs.

Outil 03 · Programmation

Python — reproduire l'analyse

Objectif : importer les données, calculer des indicateurs et produire une sortie reproductible avec la bibliothèque standard.

Exercice guidé

  1. Installe Python 3 si nécessaire.
  2. Place le script à la racine du dépôt, où le dossier data est accessible.
  3. Exécute python atelier.py.
  4. Ajoute ensuite un contrôle empêchant une division par zéro et une vérification des valeurs manquantes.
import csv
from pathlib import Path

file_path = Path("data/atelier-sinistres-synthetiques.csv")

with file_path.open(newline="", encoding="utf-8") as file:
    rows = list(csv.DictReader(file))

exposure = sum(int(row["exposure"]) for row in rows)
claims = sum(int(row["claims"]) for row in rows)
premium = sum(float(row["premium_eur"]) for row in rows)
incurred = sum(float(row["incurred_eur"]) for row in rows)

print(f"Exposure: {exposure:,}")
print(f"Claims: {claims:,}")
print(f"Frequency per 100 exposures: {claims / exposure * 100:.2f}")
print(f"Incurred per exposure: {incurred / exposure:.2f} EUR")
print(f"Aggregate loss ratio: {incurred / premium:.2%}")

for row in rows:
    freq = int(row["claims"]) / int(row["exposure"]) * 100
    print(row["segment"], f"{freq:.2f} claims per 100 exposures")

Outil 04 · Statistique

R — explorer et interpréter

Objectif : effectuer les mêmes calculs et prolonger l'analyse vers la visualisation et les diagnostics.

Exercice guidé

  1. Ouvre RStudio à la racine du projet ou adapte le chemin du fichier.
  2. Importe le CSV avec read.csv.
  3. Calcule les agrégats et les indicateurs par segment.
  4. Compare les résultats à Excel, VBA et Python.
  5. Trace le coût par exposition et formule une interprétation prudente.
data <- read.csv(
  "data/atelier-sinistres-synthetiques.csv",
  stringsAsFactors = FALSE
)

total_exposure <- sum(data$exposure)
total_claims <- sum(data$claims)
total_premium <- sum(data$premium_eur)
total_incurred <- sum(data$incurred_eur)

cat("Exposure:", total_exposure, "\n")
cat("Claims:", total_claims, "\n")
cat("Frequency per 100 exposures:",
    100 * total_claims / total_exposure, "\n")
cat("Incurred per exposure:",
    total_incurred / total_exposure, "EUR\n")
cat("Aggregate loss ratio:",
    total_incurred / total_premium, "\n")

data$frequency_per_100 <- 100 * data$claims / data$exposure
data$incurred_per_exposure <- data$incurred_eur / data$exposure
data$loss_ratio <- data$incurred_eur / data$premium_eur

print(data[, c("segment", "frequency_per_100",
               "incurred_per_exposure", "loss_ratio")])

barplot(data$incurred_per_exposure,
        names.arg = data$segment,
        xlab = "Segment",
        ylab = "Incurred EUR per exposure",
        main = "Synthetic portfolio comparison")

Validation des acquis

Ce que tu dois pouvoir expliquer

La compétence n'est pas seulement d'obtenir les mêmes chiffres : il faut savoir ce qu'ils mesurent.

  1. Pourquoi le ratio agrégé n'est-il pas la moyenne simple des ratios par segment ?
  2. Pourquoi une fréquence de sinistres par exposition n'est-elle pas nécessairement une probabilité individuelle ?
  3. Quel effet aurait une exposition mal mesurée sur la comparaison des segments ?
  4. Pourquoi le coût par exposition n'est-il pas, à lui seul, une prime pure tarifaire suffisante ?
  5. Quelles informations supplémentaires faudrait-il avant de proposer une modification de tarif ?

Critère de réussite : tu sais calculer, vérifier, interpréter et citer au moins deux limites de l'analyse.
