# ACTU-BASICS — Spécification du modèle de leçon v2

## Champs requis
- identifiant et titre FR/EN ;
- question de départ et objectifs mesurables ;
- niveau de maîtrise cible ;
- prérequis classés strict / conseillé / capsule contextuelle ;
- définitions, notations, unités et conventions ;
- explication intuitive et visualisation/interaction ;
- formalisation et exemple numérique vérifié ;
- contre-exemple, limites et erreurs fréquentes ;
- ateliers logiciels pertinents ;
- exercices gradués et corrections ;
- synthèse et références complètes ;
- script voix off, storyboard, sous-titres et statut du rendu média.

## Voies logicielles
Excel : formules, tableaux, graphiques, TCD, outil d'analyse au besoin.
Excel VBA : automatisation ciblée et code maintenable ; optionnel.
Python : pandas, NumPy, SciPy, statsmodels, scikit-learn selon la notion.
R : base R/tidyverse, ggplot2, modèles, tests et rapports reproductibles.

## Parité
Même données, observations, variables, traitement des manquants, conventions, paramètres et tolérances. Expliquer les différences propres aux fonctions.

## États de ressource
- design : fiche de conception ;
- source-authored : contenu rédigé ;
- reviewed : contrôle scientifique/éditorial terminé ;
- interactive : page et interactions testées ;
- video-scripted : voix off et storyboard préparés ;
- video-rendered : fichier vidéo vérifié ;
- published : réellement publié.

Ne jamais inférer un état à partir d'un autre.
